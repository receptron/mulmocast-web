# プロジェクトドキュメント改善コマンド

作業終了後に実行し、メタドキュメントの改善点を反映する。

## 対象ファイル

1. **CLAUDE.md** - プロジェクト概要、ソース一覧、開発ガイドライン
2. **docs/IMPROVEMENT_PLAN.md** - 改善計画、実装状況
3. **.claude/commands/update-docs.md** - Webドキュメント更新手順

## 実行内容

1. 上記3ファイルを読む
2. 今回の作業内容を振り返り、改善が必要な箇所を特定
3. 改善提案をユーザーに報告
4. ユーザーがOKしたら編集を実行

## 改善の観点

- 古くなった情報の更新
- 新しく発見したパターンやガイドラインの追加
- 実装状況の更新（IMPROVEMENT_PLAN.md）
- 手順の改善や明確化
- 不足している情報の追加
